# 브리티시 숏헤어 백과사전

브리티시 숏헤어를 품종 표준 원문과 수의학 문헌으로 정리한 단일 페이지 웹 백과사전이다. 한국어로 작성했고, 별도 빌드 과정 없이 정적 파일로만 동작한다.

## 구성

```
index.html                       본문 전체 (HTML, CSS, JS 인라인)
assets/img/                      본문 이미지
assets/logos/                    파비콘, 헤더 로고
assets/mov/cat-frames/           스크롤 연동 프레임 시퀀스
assets/mov/cat-body-frames/      스크롤 연동 프레임 시퀀스
```

## 보는 방법

로컬에서는 `index.html`을 브라우저로 바로 열면 된다. 프레임 시퀀스가 로컬 파일 정책에 걸리면 간단한 정적 서버를 띄운다.

```bash
python3 -m http.server 8000
```

## 갱신 기준

- 사실, 숫자, 출처는 품종 등록 단체의 표준 원문과 수의학 문헌을 따른다. 본문에 적힌 출처를 바꾸지 않은 채 숫자만 고치지 않는다.
- 이미지를 교체할 때 파일명 규칙(`섹션-번호.png`)을 유지한다. `index.html` 안에서 경로를 직접 참조한다.
- 프레임 시퀀스는 파일 개수와 `frame-0000.jpg` 형식의 연번을 함께 맞춘다.
